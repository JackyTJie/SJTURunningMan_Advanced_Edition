# 路线规划与导入

各平台的路线来源、格式与坐标系都在这里说清楚。

## 路线文件格式

路线就是一行一个坐标点的纯文本：

```
121.43680706489432,31.027665038002322
121.43692833613818,31.027541257648274
121.43703613279938,31.02741360898802
```

- 每行 `longitude,latitude`，即**经度在前、纬度在后**，英文逗号分隔；
- 编码为 **BD09**（百度坐标系），**不是** GPS 原生的 WGS84；
- 点的顺序即行进顺序，首尾点越接近，生成结果越自然。

## 坐标系说明

这是本项目最容易踩坑的地方：

| 坐标系 | 用在哪 |
| --- | --- |
| **WGS84** | GPS 原生；OpenStreetMap 瓦片也是 WGS84 |
| **GCJ02** | 高德 / 腾讯地图；**上传前由软件端平移校正成这个** |
| **BD09** | 百度地图；**路线文件里存的是这个** |

电脑版**路线预览的内嵌地图固定使用 OpenStreetMap**；**路线规划器默认百度地图**，可在页面内切换 OpenStreetMap。百度地图点击直接给出 BD09；OSM 点击是 WGS84，入数组前转成 BD09，因此导出的 txt 与旧路线文件、与上传流程完全兼容。手机端沿用 BD09。

> **电脑版路线规划器**默认百度地图，页面内可切换 Leaflet + OpenStreetMap；路线预览固定 OpenStreetMap；**安卓 / 鸿蒙**的路线设计页仍是百度地图 API。两端只是底图不同，导出的坐标格式一致。

## 路线规划器（电脑版）

1. 在「**路线管理**」页点「**设计路线**」，浏览器通过本机 HTTP 页面打开内置路线规划器；刷新时保持客户端运行，重启客户端后从按钮重新打开；
2. 在地图上点击选择路径坐标点，形成跑步路线（默认百度地图，可在页面内切换 OpenStreetMap）；
3. 支持**添加、删除单个点、清空全部点**；
4. 点「**下载路线 txt**」下载 `custom_route.txt`；
5. 回到「**路线管理**」页，点击「**导入 TXT**」导入该 txt。

导入后的路线会被复制到**系统用户数据目录的 `routes/` 文件夹**（位置见 [desktop.md](desktop.md)），重启后仍在。

## 内置路线与隔离区

- 电脑版内置路线当前**仅保留 `assets/Routes/default.txt`**；
- 其余历史内置路线已移到 `assets/Routes/NeedsReview/`（`BigLawn` / `BotanicalGarden` / `HanzeLake` / `NanTi` / `SiyuanLake`），待人工校验跳段、长度、起终点问题后再逐个恢复；
- 用户自己导入的路线**不受影响**，复制到用户数据目录的 `routes/`。

> ⚠️ `assets/Routes/NeedsReview/` 是待校验区，**不要**直接把它们挪回内置列表 —— 其中若干条存在跳段或长度异常，需要先按下面的方法验证。

## 校验一条路线是否可用

1. 在电脑版「选择路线」中选中该路线；
2. 工作台与路线管理会按当前单次距离自动预览（无需登录），切换路线后立即更新，地图默认展开；若已收起，点「在地图中打开」；
3. 在预览卡片内嵌的 OpenStreetMap 地图中检查：
   - 红色高亮段是否出现 —— 单段 > 150 m 说明有跳段；
   - 起点（绿）与终点（红）是否接近；
   - 路线总长是否与你的目标距离匹配。

无红色跳段、首尾接近的路线才是合格的内置候选。

## 路线设计页（安卓 / 鸿蒙）

1. 进入路线设计页，在地图上**依次连点**；
2. 点越多越贴合，**注意顺序，且起止点越接近越好**；
3. 保存后回到主界面重新开跑。

![安卓路线设计](./images/android-route.webp)

## 删除已导入的路线

电脑版「路线管理」页的「**删除**」按钮可移除用户数据目录 `routes/` 中的副本，删除前需确认，导入源文件不受影响。

- 桌面端内置路线显示为「思源湖」（内部标识仍为 `default`），**受保护**，不可删除；旧版 `user.txt` 需手动导入；
- 导入同名文件时会自动追加 `_1`、`_2` 等序号，不会覆盖已有路线。
